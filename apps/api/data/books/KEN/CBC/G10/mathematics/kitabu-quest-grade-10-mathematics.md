## Real Numbers Classification of numbers Reciprocal of numbers: Worked Example

Worked example: Classify these numbers: -4, 0.75, square root of 9, and square root of 2.

1. -4 is an integer because it is a whole number below zero.
2. 0.75 is rational because 0.75 = 3/4.
3. square root of 9 is 3, so it is a natural number, an integer, and rational.
4. square root of 2 is irrational because it cannot be written exactly as a fraction of two integers.
5. Check: every natural number is also a whole number, integer, rational number, and real number.

## Indices and Logarithms Indices Logarithms to base 10 Application of indices and: numbers in index form: Worked Example

Worked example: Simplify 2^3 x 2^4, then explain the rule used.

1. Both powers have the same base, 2.
2. When multiplying powers with the same base, add the indices.
3. 2^3 x 2^4 = 2^(3 + 4) = 2^7.
4. Evaluate if needed: 2^7 = 128.
5. Check by expansion: 2 x 2 x 2 x 2 x 2 x 2 x 2 = 128.

Answer: 2^3 x 2^4 = 2^7 = 128.
