## Numbers and Algebra: types of matrices using rows and columns: Worked Example

Worked example for Numbers and Algebra: types of matrices using rows and columns: Find the order of the matrix and the determinant if it is square.

Matrix A = [ 2  5 ]
           [ 1  3 ]

1. Count rows: there are 2 rows.
2. Count columns: there are 2 columns.
3. The order is 2 by 2, so a determinant can be found.
4. For a 2 by 2 matrix [a b; c d], determinant = ad - bc.
5. Substitute: (2 x 3) - (5 x 1) = 6 - 5 = 1.

Answer: A is a 2 by 2 matrix and det(A) = 1.

Your turn: Find the order and determinant of [4 2; 3 1].
