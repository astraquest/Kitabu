## Sets Notations Representation of sets Types of sets Operations on sets (Unions,: set notations and elements of a set: Worked Example

Worked example: In a Grade 12 club survey, 18 learners like football, 14 like athletics, and 6 like both. How many learners like football or athletics?

1. Name the sets: F = football and A = athletics.
2. The learners who like both have been counted twice, so subtract them once.
3. Use the rule: n(F union A) = n(F) + n(A) - n(F intersection A).
4. Substitute: 18 + 14 - 6 = 26.
5. Check with a Venn diagram: football-only is 12, both is 6, athletics-only is 8, and 12 + 6 + 8 = 26.

Answer: 26 learners like football or athletics.

## Binomial Expansions Binomial expansion Coefficient in binomial expansion Use binomial expansion to: expand binomial expressions up: Worked Example

Worked example: Expand and simplify (x + 3)(x + 5).

1. Multiply every term in the first bracket by every term in the second bracket.
2. x times x = x^2.
3. x times 5 = 5x and 3 times x = 3x.
4. 3 times 5 = 15.
5. Combine like terms: x^2 + 5x + 3x + 15 = x^2 + 8x + 15.

Answer: (x + 3)(x + 5) = x^2 + 8x + 15.
