## Measurements 3.1 Circles: surface area of a triangular prism: Worked Example

Worked example for Measurements 3.1 Circles: surface area of a triangular prism: Find surface area, not volume.

A closed cylinder has radius 3 cm and height 8 cm. Use pi = 3.14 to find total surface area.

1. Write the formula: total surface area = 2 pi r(h + r).
2. Substitute: 2 x 3.14 x 3 x (8 + 3).
3. Add inside brackets: 8 + 3 = 11.
4. Multiply: 2 x 3.14 x 3 x 11 = 207.24.
5. Label the answer in square units because surface area covers outside space.

Answer: 207.24 square centimetres.
