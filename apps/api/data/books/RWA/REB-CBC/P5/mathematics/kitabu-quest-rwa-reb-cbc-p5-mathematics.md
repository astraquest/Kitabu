## Reading, writing, comparing and calculating whole numbers up to 1,000,000: Learn

Reading, writing, comparing and calculating whole numbers up to 1,000,000 teaches you to read, write, compare, and calculate with large whole numbers.

Core idea:
- A digit has value because of its position: ones, tens, hundreds, thousands, ten-thousands, and hundred-thousands.
- Compare numbers from left to right, starting with the greatest place value.
- For addition and subtraction, align place values before calculating.
- For multiplication or division, check whether the answer should be bigger or smaller than the starting number.

Rwanda example: class enrolment, harvest records, market stock, and school budget totals can all use whole-number operations.

## Reading, writing, comparing and calculating whole numbers up to 1,000,000: Worked Example

Worked example for Reading, writing, comparing and calculating whole numbers up to 1,000,000: A school library has 23,475 storybooks and 18,320 revision books. How many books are there altogether?

1. Align place values.
2. Add ones, tens, hundreds, thousands, and ten-thousands.
3. 23,475 + 18,320 = 41,795.
4. Estimate: 23,000 + 18,000 = 41,000, so 41,795 is reasonable.

Answer: 41,795 books.

## Addition and subtraction of integers: Worked Example

Worked example for Addition and subtraction of integers: The morning temperature is 3 degrees above zero. At night it drops by 7 degrees. What is the night temperature?

1. Start at +3 on a number line.
2. Move 7 steps left because the temperature drops.
3. +3 - 7 = -4.

Answer: 4 degrees below zero.

## Prime factorization and divisibility tests: Learn

Prime factorization and divisibility tests helps you break numbers into useful groups.

Core idea:
- A factor divides a number exactly.
- A multiple is made by multiplying a number by 1, 2, 3, and so on.
- Prime numbers have exactly two factors: 1 and the number itself.
- Classification is easier when you test divisibility carefully.

## Prime factorization and divisibility tests: Worked Example

Worked example for Prime factorization and divisibility tests: List all factors of 24.

1. Test factor pairs: 1 x 24, 2 x 12, 3 x 8, 4 x 6.
2. No whole-number factor pair is missing between 4 and 6.
3. Write the factors in order.

Answer: 1, 2, 3, 4, 6, 8, 12, 24.

## Equivalent fractions and operations: Learn

Equivalent fractions and operations teaches how two quantities change together at the same rate.

Core idea:
- In direct proportion, when one quantity is multiplied, the other quantity is multiplied by the same factor.
- A table helps you compare matching values.
- The unit rate tells the value for one item, one litre, one metre, one hour, or one learner.
- Always check that the relationship is consistent before using proportion.

## Equivalent fractions and operations: Worked Example

Worked example for Equivalent fractions and operations: If 3 exercise books cost 900 francs, how much do 5 exercise books cost at the same price?

1. Find the cost of 1 book: 900 / 3 = 300 francs.
2. Multiply by 5 books: 300 x 5 = 1500 francs.
3. Check: more books should cost more money.

Answer: 5 exercise books cost 1500 francs.

## Multiplication and division of decimal numbers: Worked Example

Worked example for Multiplication and division of decimal numbers: Compare 4.35 and 4.5.

1. Write 4.5 as 4.50 so both numbers show hundredths.
