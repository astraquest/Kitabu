## Indices and surds: Worked Example

Worked example for Indices and surds: A bag has 4 red counters and 1 blue counter. Which colour is more likely to be picked?

1. Compare the number of counters.
2. Red has 4 chances; blue has 1 chance.
3. More red counters means red is more likely.

Answer: Red is more likely.

## Polynomials: Worked Example

Worked example for Polynomials: If 3 exercise books cost 900 francs, how much do 5 exercise books cost at the same price?

## Pythagoras's theorem: Worked Example

Worked example for Pythagoras's theorem: A classroom is 8 m long and a corridor is 350 cm long. Which is longer?

1. Convert 8 m to centimetres: 8 m = 800 cm.
