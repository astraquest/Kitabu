# Grade 1 Mathematics content provenance

## Authoritative curriculum source

The curriculum records already stored in the Kitabu database are authoritative.
The 53 mission files in this directory were mapped one-to-one to those stored
Grade 1 Mathematical Activities outcomes across three strands and eleven
sub-strands. Imported strand names, sub-strand names, outcome wording, source
identifiers, and mathematical bounds are preserved in each mission's
`curriculum` object.

## Authored layer

The interaction sequences, prompts, deterministic answers, feedback, retry hints,
and accessibility alternatives were authored with Codex on 2026-07-27. They are
new presentation and practice content; they are not imported curriculum labels.
Each outcome has six progressive interactions: warm-up, model, guided practice,
independent practice, transfer, and exit check.

The first draft introduced themed `Safari` mission titles. Those aliases were not
part of the imported data and were not product-approved. They were removed before
release. `mission.title` now exactly matches `curriculum.outcomeText`, and the
content compiler enforces that rule. Any future presentation alias must use a
separate field with explicit approval provenance.

## Generated files and validation

`index.json` is generated by
`scripts/build-grade1-mathematics-content-index.mjs`; mission files are the source
of truth for authored content. API tests validate mission count, progression,
deterministic answers, official curriculum identity, runtime registry reachability,
and supported interaction contracts.
