# PP2 Vector Pilot Asset Contract

This pilot contains exactly 100 reusable SVG assets for PP2 through Grade 3.

## Identity and storage

- Root: `learning-assets/vector-pilot/v1/<category>/<slug>.svg`
- Stable identifier: `kitabu.vector.<category>.<slug>`
- Version: `1.0.0`
- Each asset is independently listed in `catalogue.json` and the main learning asset registry.
- Use a singular, subject-neutral noun or concept for `slug`.

## SVG rules

- Use `viewBox="0 0 256 256"`; no fixed `width` or `height`.
- Use only inline vector elements (`path`, `circle`, `ellipse`, `rect`, `polygon`, `line`, `polyline`, `g`, `title`, `desc`).
- Do not use `image`, `text`, `foreignObject`, script, external URLs, fonts, embedded raster data, filters, or animation.
- Include a unique `<title>` and concise `<desc>`; use no gender, ability, or faith assumptions in shared assets.
- Use a friendly, high-contrast outlined style: `stroke="#173B5C"`, `stroke-width="10"`, rounded joins/caps, and a small Kitabu palette (`#3157A4`, `#10B981`, `#F59E0B`, `#F97316`, `#EC4899`, `#8B5CF6`, `#FFFFFF`).
- Centre the subject, leave an 18px safe margin, and make it readable at 48px.

## Reuse metadata

Every catalogue record must name at least two intended uses selected from:
`addition`, `subtraction`, `counting`, `colouring`, `matching`, `phonics`, `vocabulary`, `patterns`, `sorting`, `body-awareness`, `faith-cre`, `faith-ire`, `storytelling`, `shape-learning`.

## Quality bar

- Draw the asset as a recognisable object, not an emoji, letter glyph, or copied branded icon.
- Shape and colour assets must also work as uncluttered colouring outlines.
- Do not add worksheet/page scans or unlicensed source artwork.
